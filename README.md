# Zubaida Digital Marketing Specialist

One-page personal portfolio for a Local SEO Expert and Digital Marketing Specialist.

## Project structure

- `app/` - Next.js App Router pages and API route
- `components/` - reusable UI components
- `public/` - static assets like the favicon
- `styles/` - global Tailwind CSS styles

## Setup

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Build

- `npm run build`
- `npm start`

## Vercel deployment

1. Create a GitHub repository
2. Push this project
3. Connect the repository to Vercel
4. Set root directory to `/`
5. Deploy

## Notes

- Form action is configured for future integration at `/api/contact`
- SEO-friendly metadata and schema markup are included
